
Sistema de Controle de Estacionamento

1. Descrição do Projeto

O Sistema de Controle de Estacionamento tem como objetivo facilitar o gerenciamento de veículos, permitindo registrar entradas e saídas, consultar vagas disponíveis e manter o histórico de movimentações.

2. Funcionalidades

Operador

- Registrar a entrada de veículos.
- Consultar vagas disponíveis.
- Registrar a saída de veículos.

Administrador

- Cadastrar veículos.
- Consultar o histórico de movimentações.
- Sincronizar dados.

3. Objetivo
Organizar o controle das vagas e das movimentações dos veículos, tornando o gerenciamento do estacionamento mais simples e eficiente.

4. Sobre o Projeto
Projeto acadêmico desenvolvido na disciplina de Engenharia de Software, do curso de Tecnologia em Sistemas para Internet (TSI), no IFMS.
