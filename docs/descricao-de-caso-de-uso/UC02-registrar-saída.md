
UC02 – Registrar saída de veículo

Objetivo: Registrar a saída de um veículo do estacionamento do IFMS.

Ator: Operador da guarita.

Pré-condições:

- O veículo deve possuir uma entrada registrada no sistema.
- O sistema deve estar disponível.

Fluxo principal:

1. O operador acessa o sistema.
2. Seleciona a opção "Registrar saída".
3. Informa a placa do veículo.
4. O sistema localiza o registro de entrada.
5. O sistema apresenta os dados do veículo.
6. O operador confirma a saída.
7. O sistema registra a data e o horário da saída.
8. O sistema libera a vaga para utilização.

Fluxo alternativo:

- Caso não exista registro de entrada, o sistema informa que não encontrou o veículo no estacionamento.

Pós-condição:

- A saída fica registrada e a vaga passa a constar como disponível.
