
UC03 – Consultar vagas disponíveis

Objetivo: Permitir que o operador consulte a quantidade de vagas disponíveis no estacionamento do IFMS.

Ator: Operador da guarita.

Pré-condições:

- O sistema deve estar disponível.
- As informações das vagas devem estar registradas no sistema.

Fluxo principal:

1. O operador acessa o sistema.
2. Seleciona a opção "Consultar vagas disponíveis".
3. O sistema verifica os registros de entrada e saída dos veículos.
4. O sistema calcula a quantidade de vagas disponíveis.
5. O sistema apresenta a quantidade de vagas livres e ocupadas.

Fluxo alternativo:

- Caso não existam vagas disponíveis, o sistema informa que o estacionamento está lotado.

Pós-condição:

- A quantidade de vagas disponíveis é apresentada ao operador
