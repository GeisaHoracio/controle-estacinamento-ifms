
UC01 – Registrar entrada de veículo

Objetivo: Registrar a entrada de um veículo no estacionamento do IFMS.

Ator: Operador da guarita.

Pré-condições:

- O sistema deve estar funcionando.
- O veículo deve estar cadastrado.

Fluxo principal:

1. O operador acessa o sistema.
2. Seleciona a opção "Registrar entrada".
3. Informa a placa do veículo.
4. O sistema consulta as vagas disponíveis.
5. O sistema verifica se existe vaga disponível.
6. O operador confirma o registro.
7. O sistema salva a data e o horário da entrada.

Fluxo alternativo:

- Caso não existam vagas disponíveis, o sistema informa que o estacionamento está lotado.

Pós-condição:

- A entrada do veículo fica registrada e a vaga passa a constar como ocupada.
